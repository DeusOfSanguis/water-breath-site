Повышение инструкторцугуко

С Мидзуното на Мидзуное.

1. Проведение 1-ого события по захватам точек.
2. Проведение 1-ой лекции  тренировки  урока фехтования RP-События. (Выбор делается исходя из рода вашей деятельности)
3. Проведение физической тренировки.
4. Убейте 2 демонов

С Мидзуное на Каното.

1. Проведение 1-ого события по захватам точек.
2. Проведение 2-ух разных лекций  тренировок  уроков фехтования  RP-Событий.
3. Проведение тренировки закаливания организма.
4. Успешно убейте 3 демонов

С Каното на Каноэ.

1. Проведение 2-ух событий по захватам точек.
2. Проведение профилактической проверки устава.
3. Проведение тренировки по лопанью маленьких панкунов.
4. Успешно убейте 4 демонов

С Каноэ на Тсучиното.

1. Проведение 3-ёх событий по захватам точек.
2. Проведение профилактической проверки устава дома бабочки.
3. Проведение разведывательной миссии в ДК. [10 минут]
4. Проведение подготовки к финальному отбору.
5. Успешно убейте 5 демонов

С Тсучиното на Тсучиноэ.

1. Проведение 3-ёх событий по захватам точек.
2. Проведение лекции по рваным ранам ПМП.
3. Проведение разведывательной миссии в НТ. [15 минут]
4. Проведите 1 событие по захвату важной точки
5. Успешно убейте 6 демонов

С Тсучиноэ на Хиното.

1. Проведение 2-ух событий по захвату важной точки.
2. Проведение лекции по колотым ранам ПМП.
3. Создать любые таблетки и передать столпу (( Используя систему крафта )) Временно не работает. Можно не выполнять этот этап.
4. Проведение тренировки по уборке Штаба (Додзё, пруда, склада).
5. Успешно убейте 7 демонов

С Хиното на Хиноэ.

1. Проведение 2-ух событий по захватам важных точек.
2. Проведение лекции по переломам ПМП.
3. Проведение тренировки по заточке катаны ничирин.
4. Проведение тренировки по постоянному удержанию дыхания.
5. Успешно убейте 8 демонов

С Хиноэ на Киното.

1. Принесите на склад поместья бабочки 10 ящиков с припасами (( Используя механицу ящиков ))
2. Проведение лекции по головной боли ПМП.
3. Сразитесь со столпом своего дыхания и получите от него добро
4. Успешно убейте 9 демонов
5. Купите новую катану в Деревне Кузнецов. (( Используя магазин катан ))

С Киното на Киноэ.

1. Проведение 3 события по захвату точек.
2. Проведение лекции по открытым и закрытым переломам ПМП.
3. Провести захват 3-ех важных точек
4. Скрафтить 2 любые таблетки и передать их столпу воды. Временно не работает. Можно не выполнять этот этап.
5. Одобрение на повышение от Кагая Убуяшики.
6. Убить 2-ух Низших Лун в одиночку.
7. Успешно убейте 10 демонов
