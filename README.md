# Дыхание Воды — сайт фракции

Сайт фракции **Дыхание Воды** в стиле добра + воды, сделан на основе [bloodpact-site](https://github.com/DeusOfSanguis/bloodpact-site).

**Домен:** https://water-breath-yufu.ru/ (настраивается, аналог bloodpact.su)

Хостинг — **GitHub Pages**: публикуется корень ветки `main`, домен `water-breath-yufu.ru` через файл `CNAME`.

---

## Тема — светлая вода + тёмный океан

Сделано 2 темы с переключателем в шапке (☾/☀), сохраняется в `localStorage`:

- **Светлая (по умолчанию, добро):** `#f4f9fd` фон, белые карточки, синий акцент `#1e8cb8`, тёмный текст `#10202e` — чистота, поместье Бабочки
- **Тёмная (ночной океан):** `#050c18` фон, `#0a1a2a` карточки, `#3ab4e0` свечение, светлый текст `#e0f0f8` — кинематографичность как у bloodpact, но вода

Цвета — в `:root` в `content/theme.css`, иероглиф раздела — 水 вместо 血.

Обложки: `assets/img/water-moon.jpg` (ночь, луна над водой), `water-surface.jpg` (дневная вода), `butterfly-estate.jpg` (сад поместья) — без людей, только места.

## Как править тексты

В админке `/admin/` или руками в `content/`:

```bash
python3 build.py
git add -A && git commit -m "Правки" && git push origin main
```

Заголовки, картинки обложек, цитаты, порядок меню и домен — в `content/pages.json`.

Локально: `python3 -m http.server 8000` → http://localhost:8000/

## Анимации ката (сделано)

Гифки 1–10 конвертнуты в **mp4 (H.264)** — это в 5–10 раз легче и играется в `<video>`:

| Файл | Что это | Размер |
|---|---|---|
| `assets/kata/01…10-kata.mp4` | сама анимация | ~100–1000 КБ каждый |
| `assets/kata/01…10-kata-poster.jpg` | кадр-постер (виден до загрузки) | 5–30 КБ |

Итого было **40 МБ гифок → ~5 МБ mp4**. Оригиналы (`.gif`) в репозиторий не кладутся — `.gitignore` их не пускает.

**Как это встроено** (`{{kata}}` в `content/kata.html`, превью на главной — `{{kata-teaser}}`):

- видео **ленивое**: `preload="none"`, `src` подставляется скриптом, когда карточка подъехала к экрану (атрибуты `data-src` в `<source>`);
- на компьютере анимация играет **при наведении**, на телефоне — по кнопке ▶ (тап по карточке тоже работает);
- одновременно играет только один ролик, при уходе со страницы / сворачивании окна — пауза;
- у каждой формы свой постер, пока ролик не загружен.

**Если понадобится переконвертировать** (например, добавили новую форму):

```bash
# mp4 (основной формат, играет везде)
ffmpeg -i "1 ката.gif" -an -vf "scale=trunc(iw/2)*2:trunc(ih/2)*2" \
  -c:v libx264 -crf 25 -preset slow -pix_fmt yuv420p -movflags +faststart \
  assets/kata/01-kata.mp4

# постер (кадр из 30% ролика)
ffmpeg -ss 1 -i assets/kata/01-kata.mp4 -frames:v 1 -q:v 5 \
  assets/kata/01-kata-poster.jpg

# webm — необязательный второй источник (меньше весит, но кодируется дольше)
ffmpeg -i "1 ката.gif" -an -vf "scale=trunc(iw/2)*2:trunc(ih/2)*2" \
  -c:v libvpx-vp9 -crf 34 -b:v 0 -row-mt 1 -cpu-used 3 assets/kata/01-kata.webm
```

После этого в `content/data/kata.json` (или в админке, вкладка **Ката**) указать поля:

```json
{ "id": 1, "video": "assets/kata/01-kata.mp4", "webm": "", "poster": "assets/kata/01-kata-poster.jpg" }
```

Если видео нет вовсе — на сайте останется заглушка «Анимация формы N — скоро».

## Вкладки, переходы, курсор (сделано)

**Вкладки-разделы в шапке** — новый вариант: вместо круглых печатей-«таблеток» теперь
жидкая полоса (`content/theme.css`, блок «шапка: вкладки-разделы»):

- стеклянная капсула с размытием, иероглиф раздела в круге + подпись;
- за активной вкладкой едет **капля-подсветка** (`.ntabs__ink`) — пружинная анимация;
- при наведении над вкладкой всплывает капелька, под полосой бежит волна;
- лента сама подкручивается так, чтобы активная вкладка была посередине;
- на телефоне подписи прячутся, остаются иероглифы.

**Переход между страницами** — «штора-волна» (`.veil` в `content/theme.css`, модуль 11 в `content/app.js`):

- уходим со страницы: снизу поднимается вода с волной, показывает иероглиф и название раздела, счётчик-полоса добегает — и переход;
- приходим: штора уже накрыта (класс `veil-cover` ставится инлайн-скриптом в `<head>`, до первой отрисовки), поэтому белой вспышки нет — вода просто уезжает вверх и открывает новую страницу;
- без JS шторку убирает CSS-анимация, при `prefers-reduced-motion` штора не показывается вовсе.

**Водный курсор** — `.wcur` (модуль 10):

- свечение, кольцо и капля-ядро идут за мышью с разной задержкой — «жидкий» шлейф;
- при наведении на ссылки и карточки кольцо расширяется;
- клик — рябь двумя кругами и брызги, быстрое движение мышью — капли-след;
- на тач-устройствах (`pointer: coarse`) и при `prefers-reduced-motion` курсор просто не создаётся.

Отключить любой эффект можно в `content/app.js`: модули 10 (курсор) и 11 (переходы) — отдельные самовызывающиеся функции, удаляются без последствий.

## Отличия от bloodpact-site

- Палитра: вместо кроваво-красного `#d3132a` — водный синий `#1e8cb8` / `#3ab4e0`
- Фон: светлый `#f4f9fd` по умолчанию + тёмный океан `#050c18` переключателем
- Иероглифы: 血 → 水, 法, 律, 型, 蝶, 位
- Герой: «Стань как вода» + «течение не остановить» вместо «Возгордись своей расой»
- Цитаты: Томиока Гию и Урокодаки вместо Лун и Мудзана
- Контент: устав истребителей, кодекс воды, ката, поместье Бабочки
- Админка: 5 вкладок (состав, ката, повышения, рейтинг, цитаты) вместо 3
- Гифки ката: mp4 + постер, ленивая загрузка, играет по наведению/тапу (было 40 МБ гифок)
- Вкладки-разделы в шапке: жидкая полоса с каплей-подсветкой вместо печатей
- Переходы между страницами: штора-волна с иероглифом и названием раздела
- Водный курсор: свечение, кольцо, рябь при клике и капли-след
